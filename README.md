# 🎓 Task 8: Student Performance Prediction Using Machine Learning

## Synent Technologies Data Science Internship

### 📌 Project Overview

This project focuses on predicting student academic performance using Machine Learning techniques. The objective is to analyze student-related factors and build a predictive model capable of estimating student performance accurately.

The project was completed as part of **Task 8 – Machine Learning Model** in the Synent Technologies Data Science Internship Program.

---

## 🎯 Problem Statement

Educational institutions often seek to identify factors that influence student performance. Predictive models can help educators understand these factors and make data-driven decisions to improve academic outcomes.

The goal of this project is to develop a machine learning model that predicts student performance based on various academic and personal attributes.

---

## 📊 Dataset Details

**Dataset Name:** StudentPerformance.csv

### Description

The dataset contains information related to student demographics, study habits, and academic characteristics that influence performance.

### Objective

Predict student performance using machine learning algorithms after performing data preprocessing and feature selection.
